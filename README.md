# 마드모아젤 공식 인스타 — 승인 발행 파이프라인

세종시 미용실 브랜드 '마드모아젤헤어' 공식 인스타그램 콘텐츠 파이프라인.
'원장님몰래' 검증 파이프라인(2026-08-03 복제 가이드)을 복제, **승인 필수 모드**로 변경한 채널.

## 원장님몰래와 다른 점
- **승인 후 발행**: 무인 발행 아님. `[승인 대기]` 이슈에 `승인` 댓글이 있어야만 게시. `stop`/`거부`는 종료. 승인 없으면 게시하지 않음.
- **주 2회 (화·금)**: 램프업. 안정 확인 후 주 3~5회 확대 검토.
- 시리즈 2축: STORY(디자이너·브랜드 철학) / CARE NOTE(고객용 케어 팁)
- 디자인: 에디토리얼 v2 — 아이보리 지면(#F6F1EA) + 헤어라인 프레임 + 세리프 타이포, STORY 로즈(#A85D72) / CARE NOTE 세이지(#6E8B74)
- 가드레일: 수치·실적 자랑 금지, 디자이너 실명은 동의 확인분만, 의료 효능 표현 금지, 가격 정보는 본사 지정분만 (상세: guide.md)

## 필요 Secrets (Settings → Secrets and variables → Actions)
- `ANTHROPIC_API_KEY` — 콘텐츠 생성
- `IG_USER_ID` / `IG_ACCESS_TOKEN` — 공식 계정 Instagram Graph API (60일 갱신)
