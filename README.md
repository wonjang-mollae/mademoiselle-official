# 마드모아젤 공식 인스타그램 — Codex 제작 · Claude 운영

## 현재 역할

- 콘텐츠·이미지 제작과 API 반입: Codex(GPT)
- 운영보고·감시·장애 대응·발행 파이프라인 관리: Claude
- 최종 게시 승인: 대표. GitHub 승인 대기 이슈의 승인 후 화·금 슬롯에서 게시한다.

## 제작과 반입

제작 전 원격 HANDOVER.md 최신본의 콘텐츠 규격과 가드레일을 읽는다. 직접 반입의 최신 연결 결과는 API연결현황.md를 함께 읽는다.

카드 5장(표지 1 + 본문 3 + CTA 1), 각 1080×1350 PNG와 지역 태그를 포함한 caption.txt를 준비한다. 반입 파일명은 posts/YYYY-MM-DD/card1.png~card5.png 및 caption.txt다. 이미지·캡션·원본 로고·사실 근거를 검수한 후 반입한다.

반입과 게시 승인은 별개다. Claude는 반입 회차의 폴더와 .last_post_dir, 승인 대기 이슈가 같은 콘텐츠를 가리키는지 확인한다. 이미 게시된 회차를 다시 등록하지 않는다. 대표의 승인이 없으면 게시하지 않는다.

## 기존 자동 제작 전환

대표 요청에 따라 Claude API를 호출하던 generate.js, collect_topics.js 및 두 자동 실행 워크플로를 제거했다. 원본은 Git 이력에 보존된다. 기존 게시·지표 수집·수동 반영 도구와 대기 콘텐츠는 유지한다.

콘텐츠는 Codex가 제작해서 직접 반입한다. 이 변경만으로 Codex의 새로운 예약 제작 작업이 생성되지는 않는다. 주 2회는 기존 게시 운영 기준이다.

## 운영 연결

IG_USER_ID와 IG_ACCESS_TOKEN은 GitHub Actions 비밀 설정에서만 관리한다. 값을 문서·대화·소스에 기록하지 않는다. Claude 콘텐츠 생성 API 호출은 현재 실행 코드에서 제거되었으며, API 키 자체의 폐기 여부는 API연결현황.md의 실제 상태를 따른다.
